## 已完成内容

### 本地归档与安全

- `.abk` v1/v2 保持可读；新归档写为 v3。
- v3 使用 AES-256-GCM，错误密码、密文或认证标签篡改会失败。
- 保存符号链接/目录联接目标、owner/group/DACL 安全描述符；不递归跟随重解析点。
- 默认拒绝绝对链接和含 `..` 的逃逸链接；设备和活动命名管道不作为普通文件读取。
- 统一 `OperationContext` 提供取消和阶段/文件/字节进度回调，旧 `Packer` API 保持兼容。

### 自动与实时备份

- 支持标准 5 段 Cron 的 `*`、列表、范围和步长语法。
- 任务以版本化 JSON 持久化，密码存入 Windows Credential Manager。
- 支持保留最近 N 个成功快照，默认 3 个；淘汰时清理不再引用的本地块。
- 使用 `ReadDirectoryChangesW` 递归监控，GUI 调度层执行 3 秒静默合并和 30 秒最长等待。
- 仓库位于监控源内时自动忽略仓库自身事件。
- 关闭主窗口后进入系统托盘；显式退出才停止自动任务。

### 增量仓库

- 本地仓库由 `config.bin`、`chunks/<前两位>/<sha256>.blk` 和加密快照清单组成。
- 默认固定块为 4 MiB；相同 SHA-256 块只保存一次，第二次快照可零新增数据块。
- 块和清单分别使用随机 Nonce 的 AES-256-GCM；恢复时再次校验明文 SHA-256。
- 单个块独立提交，已验证块可供下次操作复用；未完成操作不会发布快照清单。
- 支持单文件、多文件、目录、筛选、按快照恢复、取消和版本淘汰。

### 网络原型

- `DBackupServer` 强制 TLS，默认 `127.0.0.1:8443`，使用 Qt HTTP Server 和 SQLite。
- API：注册、登录、注销、缺块查询、块上传/下载、快照提交/列表/读取/删除。
- 密码使用 PBKDF2-SHA256；Token 为随机 256 位值，数据库只保存 Token 哈希，24 小时过期。
- 所有查询绑定用户 ID，块只在单用户范围去重；快照提交和引用计数使用事务。
- 删除快照后回收引用为零的服务端块；上传通过临时文件原子提交。
- 远程客户端支持 Token 凭据、缺块查询、块上传/下载、快照提交/列表/删除，由此形成块级秒传和续传基础。

- Qt 6.8.3（Widgets、Network、Sql、HttpServer）与配套 MinGW 13.1 已完成 Release 构建；`BackupTool.exe` 无显示启动冒烟通过。
- `DBackupServer.exe` 已验证 SQLite 插件和 localhost TLS：注册、登录、块上传/查缺、用户隔离、快照提交/列表/读取/删除、注销及失效 Token 均通过。

- `build.bat package` 已生成便携 ZIP，并已在全新解压目录完成 GUI 启动及服务器 TLS 注册冒烟；仍需另一台电脑做最终独立环境验证。

# DBackup 1.0 发布说明

- 支持多文件和多目录备份，归档使用 AES-256-GCM 认证加密。
- 历史 `.abk` 格式不受支持；请使用当前版本重新创建备份。
- 支持 zlib 压缩、AES-256-GCM、六类筛选和扫描预览。
- 支持内容寻址增量仓库、快照历史、去重和原子提交。
- 支持 Cron 任务、目录实时监控、系统托盘和开机启动。
- 提供 TLS DBackup Server，支持账户隔离、块查询、上传、下载和快照 API。
- 新增 Git Bash 独立验收数据与恢复比较工具。

当前版本仅支持 Windows 10/11。服务器面向本机和受信局域网，不定位为可直接暴露到公网的托管服务。

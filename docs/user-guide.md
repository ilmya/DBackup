# DBackup 用户指南

## 启动

在项目目录运行 `bash build.sh`，脚本会构建并启动程序。WSL 用户在 Ubuntu 终端运行该命令，WSLg 会将程序显示为独立窗口。添加备份文件或文件夹时，选择器默认打开当前 Linux 用户的主目录，例如 `/home/ilm`；也可以手动浏览其他位置。

中文界面需要系统中文字体，例如 Ubuntu 的 `fonts-noto-cjk`；安装后重新启动应用。测试权限、链接和实时监控时应优先选择 WSL 原生文件系统，而非 `/mnt/e`。

## 完整归档与恢复

在“新建备份”选择来源、完整归档、保存位置和可选密码；需要时设置筛选并查看预览，再开始备份。恢复时选择归档和目标目录，输入相同密码。密码无法找回，请自行妥善保存。

## 增量仓库

选择增量仓库目录和密码后创建快照。历史页面可浏览快照、恢复或删除；保留策略只应在确认保留版本可恢复后使用。备份与恢复均建议定期核对文件内容和元数据。

不要直接修改仓库配置、快照清单或数据块。权限、UID/GID 的恢复受当前账户权限和目标文件系统支持情况影响；操作失败时请查看应用提示。

## 自动任务和远程服务

计划任务使用 Cron 表达式；实时任务在应用运行期间监控文件变化。任务密码和远程登录凭据通过 Secret Service 保存，需可用且已解锁的桌面密钥环。WSL 中如无 D-Bus/密钥环会话，程序应报告凭据操作失败。

远程服务的证书和启动方式见 [服务器指南](server-guide.md)。请在受信网络中使用 HTTPS，并在首次连接自签名证书时核对指纹。

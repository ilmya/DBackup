# DBackup 用户指南

## 启动

在项目目录运行 `bash build.sh`，脚本会构建并启动程序。WSL 用户在 Ubuntu 终端运行该命令，WSLg 会将程序显示为独立窗口。在备份页的文件树中勾选文件或文件夹；目录包含后续新增的子项，取消勾选的子项不备份。树中可展开 Linux 主目录和其他挂载位置。

中文界面需要系统中文字体，例如 Ubuntu 的 `fonts-noto-cjk`；安装后重新启动应用。测试权限、链接和实时监控时应优先选择 WSL 原生文件系统，而非 `/mnt/e`。

## 完整归档与恢复

程序启动后直接进入“新建备份”，此页面用于创建完整归档。选择来源及保存位置，使用单选按钮选择打包格式，勾选“压缩”后选择压缩算法，勾选“加密”后输入 AES 密码。需要时设置筛选并查看预览，再开始备份。恢复时选择归档和目标目录，程序自动识别格式；加密归档需要输入相同密码。密码无法找回，请自行妥善保存。

打包可选择 DBackup 自定义格式或 POSIX pax tar，压缩可选择不压缩、Huffman、LZ77 和 DEFLATE。完整归档按块处理，不再受旧版 2 GiB 封装限制；备份和恢复需要额外空间存放临时打包数据，空间不足时操作会失败。新封装不兼容旧版 DBackup 封装。仅选择 tar 且不压缩、不加密时生成标准 `.tar`，可使用系统 `tar`；tar 加压缩或加密时使用 DBackup 恢复。加密归档会先完成认证，再恢复文件；未加密归档的摘要用于检测意外损坏，不能防止恶意篡改。备份完成显示的 MD5 只供摘要展示，不能用于认证文件；纯 tar 不提供内容完整性认证。选择单个目录进行新备份时，恢复目录下会保留该目录本身。

筛选可配置路径、类型、名称、修改日期、大小和所有者；文件类型页可选择普通文件、目录、符号链接、硬链接、FIFO、设备和套接字。日期按系统本地时间解释。扫描预览显示各类型的包含、排除数量和不可读文件提示。新建自动任务时会保存备份页当前的筛选规则。

FIFO、字符设备、块设备和路径型 Unix 套接字按类型及必要元数据记录，不读取其内容。恢复设备节点通常需要相应权限，目标文件系统必须支持。套接字恢复的是文件节点，不包含原服务或连接，且可能占用服务路径。tar 使用 DBackup 的 PAX 扩展保存套接字；其他 tar 工具可能将其恢复为空文件。没有文件路径的抽象命名空间套接字不属于文件树备份范围。

读取权限不足的来源会跳过并报告，结果标记为部分完成；若所有内容均不可备份则报告失败。恢复时权限不足或文件系统不支持的项目也会报告。路径逃逸、危险链接和损坏数据仍会被拒绝。

## 增量仓库

在自动任务中新建计划并选择增量仓库目录和密码，通过立即运行或自动触发创建快照。选中计划并打开“详情”，可加载和恢复历史版本；保留策略只应在确认保留版本可恢复后使用。备份与恢复均建议定期核对文件内容和元数据。

不要直接修改仓库配置、快照清单或数据块。权限、UID/GID 的恢复受当前账户权限和目标文件系统支持情况影响；操作失败时请查看应用提示。

## 备份计划

在“自动任务”页新建或编辑计划，选择来源、筛选规则、保存目录和备份类型。独立归档可手动或定时执行；版本仓库和增量归档模式还可启用实时监控。可在列表立即运行、启用或停用计划，并查看最近结果。自动归档使用计划标识和随机文件名；保留数量仅作用于该计划生成的归档。部分完成或失败不会触发保留清理。

计划列表显示最近一次完整成功的时间；部分完成、失败或取消不会更新该时间。旧计划若最近结果不是完整成功，历史成功时间显示为暂无。

纯 tar 可使用系统 tar 查看；加密或压缩后的 DBackup 封装和版本仓库使用 DBackup 恢复。计划密码存放在桌面密钥环，保存或读取失败时需检查密钥环状态。活动日志记录执行阶段、路径与错误；关闭程序或停止 WSL 后，定时和实时任务暂停。

## 自动任务

新计划选择定时或实时其中一种；定时任务使用 Cron 表达式，实时任务在应用运行期间监控选中来源。原有同时启用两种方式的计划保持原状，编辑时需选择一种。Cron 的问号提示说明五个字段、范围和示例；日期和星期都受限时满足任一条件即可；星期 0 或 7 表示周日。该语义与旧版不同，请检查原有计划。关闭窗口后程序可在托盘中继续运行；程序退出或 WSL 停止时任务暂停。任务密码通过 Secret Service 保存，需可用且已解锁的桌面密钥环。

实时任务的最近结果列出本次检测到的变化；为生成可恢复的完整快照，程序仍会扫描所选来源。若其他来源持续不可读，快照仍标记部分完成，完整原因可在活动日志及快照详情中查看，部分快照不会触发保留清理。

### 增量归档

在计划的备份模式中选择“增量归档”，可选择自定义格式或 tar、压缩算法及是否加密。计划在所选保存目录下创建以计划标识命名的独立备份目录；该目录不能位于备份来源之内。第一次生成完整归档，后续归档保存变化文件及删除记录；完整备份后产生六个增量版本，再生成新的完整备份。硬链接组发生变化时也会提前生成完整备份，以保留链接关系。程序会扫描并计算文件摘要；文件不可读时不会提交不完整的增量版本。为兼容已有计划，备份目录名称仍沿用 `tar-incremental` 后缀。

在“自动任务”页选中计划并打开“详情”，程序会自动加载历史，选择版本后即可恢复。查看历史无需密码；恢复时密码框默认填入计划已保存的密码，也可输入所选版本的密码。无法读取计划密码时，可在编辑计划中重新保存。增量归档的历史显示每次备份时添加、修改和删除的文件。恢复会创建一个不存在的新目录，不会覆盖已有目录。成功备份并完成清理后，最多保留设定数量的最新版本；如有必要，程序先将最早保留的版本整理为完整归档。整理需要额外空间，失败时会报告错误并保留尚需的旧版本；修改保留数量后在下次成功备份时清理。不要手动修改或单独删除链中的归档和清单。

新建增量版本会另外保存未加密的文件变化摘要，以便不使用密码查看；能访问备份目录的人也能读取文件名和变化类型。该摘要未经认证，只用于显示，恢复时仍需原有密码并校验加密备份。旧版本若没有摘要，只显示版本目录信息。

新版本目录使用本地时间（包括毫秒）和类型命名，例如 `20261111-201830123-full` 或 `20261111-202512456-incremental`；旧目录仍可使用。每个版本目录中包含归档和 `manifest` 清单：未压缩、未加密的 tar 命名为 `archive.tar`，自定义格式或经过压缩、加密封装的归档命名为 `archive.abk`。旧版本中没有扩展名的 `archive` 仍可读取和恢复；请使用 DBackup 恢复完整版本链。

整理增量归档时会在备份目录临时还原文件，包括加密备份的明文；正常结束后会清理临时文件。异常断电或进程被强制终止时，临时目录可能残留，请保护备份目录的访问权限和存储介质。

增量归档模式已覆盖自动化的备份、恢复、清理、加密和实时触发场景；实际桌面环境与具体文件系统仍可能表现不同。请定期在实际目标环境中验证恢复结果，并保留独立副本。


## 演示与提权验收

使用 `bash test.sh` 对已有三组演示数据执行备份、恢复和逐项比较；默认启用加密，演示密码固定为 `123`，可用 `--no-encrypt` 关闭。其他参数和报告位置见[开发与测试指南](development-guide.md#独立演示数据验收)。普通用户先运行 `bash build.sh test`，再可自行执行 `sudo bash test.sh --group special-files` 验证提权下的特殊文件。检查报告，只有没有 FAIL、SKIP 或 BLOCKED 才表示该组完整通过；WSL 或文件系统可能不允许创建设备节点。**不要打开块设备占位节点。**

该脚本调用与 GUI 相同的核心，不代表 GUI 交互已验收。正在运行的 GUI 进程不能临时获得 root 权限；以 root 启动 GUI 会改变桌面会话和密钥环环境。

## 故障排查

- **Qt 找不到或窗口不显示**：安装 Qt 6.5+ 的 Linux GCC Widgets 套件，设置 `QT_ROOT`；WSL 中检查 WSLg。
- **中文显示为方框**：安装 `fonts-noto-cjk` 并重启应用。
- **无法保存密码**：检查 D-Bus 用户会话及已解锁的 Secret Service 密钥环。
- **恢复权限、属主或设备失败**：检查当前用户权限和目标文件系统能力，优先使用 WSL 原生文件系统；查看部分完成和日志中的具体项目。
- **归档无法读取**：检查路径、密码及文件是否完整；旧版 `DBPK0001` 封装不受新版本支持。
- **实时监控无事件**：检查来源存在且可访问，并在 Linux 原生文件系统排除 Windows 挂载盘的事件语义差异。

# DBackup 用户指南

## 开始使用

1. 运行 `BackupTool.exe`。
2. 在“新建备份”中通过“添加来源”选择一个或多个文件、文件夹。
3. 选择“便携完整归档”或“版本化增量仓库”。
4. 设置保存位置、压缩等级和密码。增量仓库必须设置密码。
5. 需要时打开“配置筛选规则”，然后执行“扫描预览”。
6. 点击“开始备份”，直到状态栏显示完成。

## 备份方式

- **便携完整归档**：所有内容保存在一个 `.abk` 文件中，适合携带、移动和单次交付。
- **版本化增量仓库**：只保存新增或变化的数据块，可从历史快照恢复，适合长期备份。

加密使用 AES-256-GCM。密码无法被程序找回，应保存在可靠的密码管理器中。

## 恢复数据

1. 打开“恢复数据”。
2. 选择 `.abk` 归档和空的恢复目录。
3. 对加密归档输入密码。
4. 点击“开始恢复”。
5. 恢复完成后不要只查看文件数，应按 [测试指南](testing-guide.md) 比较内容和元数据。

## 筛选

筛选面板可按路径、项目类型、名称、修改时间、尺寸和所有者组合规则。在正式备份前使用扫描预览，确认包含数量、排除数量和总容量。

## 计划与实时备份

“任务计划”可设置备份来源、仓库、Cron 时间、保留数量和实时监控。密码保存在 Windows 凭据管理器，不写入任务 JSON。

关闭主窗口后 DBackup 继续在系统托盘运行。只有托盘菜单的“退出”会停止任务。

## 远程服务器

在“存储位置”中输入 HTTPS 地址并注册或登录。首次连接自签名证书时，必须与服务器管理员核对 SHA-256 指纹。指纹变化可能意味着服务器换证书或连接被拦截，不应未核对就重新信任。

## 支持边界

DBackup 支持 Windows 10/11。活动命名管道和 Windows 设备对象不是可持久化普通文件，程序会明确拒绝。远程服务适用于本机和受信局域网，不应直接暴露到公网。

# DBackup 故障排查

| 现象 | 处理方法 |
|---|---|
| 无法启动，提示缺少 Qt DLL | 使用 `build.bat package` 生成的完整 ZIP，不要只复制 EXE。 |
| 服务器提示没有 TLS 后端 | 确认发布目录含 Qt TLS 插件、OpenSSL 3 DLL，然后重新打包。 |
| 证书指纹改变 | 停止连接，向管理员核对新指纹。未确认原因前不要替换信任记录。 |
| 符号链接无法生成或恢复 | 启用 Windows 开发者模式，或使用具有“创建符号链接”权限的账户。 |
| ACL 恢复不完整 | 使用具有恢复权限的账户，并确认目标磁盘为 NTFS。 |
| 实时备份反复触发 | 确认输出仓库不与来源共用目录；如必须共用，确认仓库已被自动排除。 |
| 恢复报告密码错误或校验失败 | 检查密码；如密码正确，按损坏备份处理，不要强制跳过 GCM 或哈希校验。 |
| Git Bash 找不到 Python | 安装 Python 3，并确认 `py.exe`、`python.exe` 或 `python3` 之一在 PATH 中。 |
